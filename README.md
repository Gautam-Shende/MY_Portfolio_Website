## 📋 About

Modern, animated portfolio showcasing my MERN Stack development journey. Features smooth animations, dark mode, and interactive 3D elements.

## ✨ Key Features

- ⚡ Blazing fast with Vite
- 🎭 Smooth Framer Motion animations
- 🌙 Dark/Light theme
- ⌨️ Typewriter effect
- 📧 Working contact form
- 📱 Fully responsive

## 🛠️ Tech Stack

- **Frontend:** React 18, Tailwind CSS
- **Animations:** Framer Motion, Three.js
- **Build Tool:** Vite
- **Email:** EmailJS
- **Icons:** Lucide React
